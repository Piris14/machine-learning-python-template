# 🧠 Machine Learning Python Template – Bootcamp Final Projects

This repository contains all the projects developed during the Data Science and Artificial Intelligence bootcamp.  
Each project is implemented in its own notebook with a complete structure: from initial data exploration to final model training.

## 📁 Project Structure
```
.
├── data/ 
├── models/ 
├── src/ # Project notebooks
│ ├── Deep_learning.ipynb # Deep neural network (CNN)
│ ├── ML_Algorithm.ipynb # Comparison of classic ML algorithms
│ ├── NPL.ipynb # Natural Language Processing (TF-IDF, BoW)
│ ├── app.py 
│ ├── k-medias.ipynb # K-Means Clustering
│ ├── k_vecinos.ipynb # K-Nearest Neighbors classification
│ ├── lineal_regularizado.ipynb # Regularized Linear Regression (Ridge/Lasso)
│ ├── naive_bayes.ipynb # Naive Bayes Classifier
│ ├── primer_EDA.ipynb # Initial exploratory data analysis
│ ├── regresion_lineal.ipynb # Linear Regression
│ ├── serie_temporal.ipynb # Time Series Forecasting
│ ├── tree.ipynb # Decision Trees and Random Forest
│ ├── utils.py # Common utility functions
├── README.md # English version
├── README.es.md # Spanish version
├── requirements.txt # Project dependencies
├── .gitignore / .env.example # Config and environment variables
```

---

## 📌 Project Overview

| Notebook                      | Technique or Model Applied                |
|-------------------------------|-------------------------------------------|
| `Deep_learning.ipynb`         | Deep Learning (CNN with image input)  
| `ML_Algorithm.ipynb`          | Comparison of classic ML models with hyperparameter tuning  
| `NPL.ipynb`                   | Text processing (NLP)  
| `k_vecinos.ipynb`             | Classification with KNN  
| `k-medias.ipynb`              | Clustering with K-Means  
| `lineal_regularizado.ipynb`   | Ridge and Lasso Regression  
| `naive_bayes.ipynb`           | Naive Bayes Classification  
| `primer_EDA.ipynb`            | General exploratory data analysis  
| `regresion_lineal.ipynb`      | Linear Regression  
| `serie_temporal.ipynb`        | Time Series Prediction  
| `tree.ipynb`                  | Decision Trees and Random Forest
